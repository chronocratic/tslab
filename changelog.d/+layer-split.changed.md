TSLab is now split into `tslab.lab` (runs, stages, studies, jobs, command line; no torch), `tslab.ml` (Lightning training, `Tensors`, `Checkpoint`, trackers) and `tslab.ts` (time series interfaces, stages, probes, chronocratic adapters), with docs and tests split the same way. This is a clean break: old import paths are gone with no shims, and old run folders, caches and saved configs do not load and must be produced again. Torch seeding and torch metadata now happen only when `tslab.ml` is imported. `tslab new` takes `--template lab|ts`.
