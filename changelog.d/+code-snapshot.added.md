Opt-in code snapshots for study jobs: `study submit --code-snapshot` (or `code_snapshot = true` in `tslab.toml`) copies `src/` into a content-addressed folder the jobs import, so queued and resubmitted runs keep the code of submit time; `study resubmit --new-code-snapshot` and `--no-code-snapshot` change the code a resubmit runs, and untracked files under `src/` stop the submit with their list.
