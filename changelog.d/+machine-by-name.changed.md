`--machine` takes a name or a path. A name is `machines/<name>.toml` in the working directory or the nearest folder above it, else an entry of the register that `tslab machine add <name> <path>` fills (`tslab machine list` and `tslab machine remove <name>` manage it; the file is `$TSLAB_MACHINES_FILE`, `$XDG_CONFIG_HOME/tslab/machines.toml` or `~/.config/tslab/machines.toml`). Jobs run in the folder that holds the `machines/` folder of the profile.
