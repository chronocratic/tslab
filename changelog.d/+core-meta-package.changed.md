Run and instance metadata now live in the `tslab.core.meta` package: the run metadata functions are in `tslab.core.meta.run`, and the instance-metadata helpers (`can_resume`, `stale_reason`, `identity_from_meta`, `read_instance_meta`, `instance_meta_document`, `describe_inputs`, `describe_external_inputs` and `INSTANCE_META_FORMAT_VERSION`) are in `tslab.core.meta.instance`. Existing `tslab.core.meta` imports keep working; `INSTANCE_META_FORMAT_VERSION` is no longer importable from `tslab.core.stage`.
