`tslab machine list` shows the profiles in `machines/` above the working folder next to the registered names, as a table, and says how to add one when there is none. Command lists in `--help` show one line per command, in workflow order; option help shows plain metavars such as `--watch SECONDS` instead of `{None}|FLOAT`. `tslab study status` lists at most 20 runs that are not done and points at `submit --dry-run` when nothing ran yet; `tslab study results` says how many rows it wrote; a missing study module or machine name gives a shorter error with the fix.
